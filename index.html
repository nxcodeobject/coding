Kenapa NxCode

Satu binary, tanpa runtime berat. Bekerja di Windows, Linux, dan macOS.

◑

Agent Build & Plan

Dua mode bawaan: Build untuk mengeksekusi perubahan, dan Plan untuk menyusun rencana sebelum menyentuh kode. Beralih kapan pun.

◇

Model apa pun, kunci Anda

Pakai kunci API provider favoritmu — Anthropic, OpenAI, Google, hingga model lokal. Tidak ada perantara, tidak ada markup.

▤

Server & Web UI

nxc web / nxc serve menjalankan server lokal dan membuka antarmuka web — akses sesi dari browser atau perangkat lain di jaringan.

⚙

Ekstensi MCP

Hubungkan MCP server untuk memberi agent alat tambahan: database, browser, API internal, dan lainnya lewat nxc.json.

⌘

Paham kode (LSP)

Terhubung ke language server sehingga agent melihat kesalahan tipe, simbol, dan definisi yang akurat sebelum mengusulkan perubahan.

⟲

Session & snapshot

Setiap percakapan tersimpan. Ekspor/impor, lanjutkan sesi lama, dan kembalikan perubahan berkat snapshot otomatis.

Instal dalam 3 langkah

1

Pasang NxCode

Jalankan perintah instalasi di hero di atas sesuai sistem operasimu.

2

Buka proyek

cd folder-proyek
3

Hubungkan & mulai

nxc

Lalu ketik /connect untuk mengisi API key provider.

Butuh instalasi manual? Unduh nxc-windows-x64.zip atau nxc-linux-x64.tar.gz dari halaman rilis.

Perintah penting

nxcMulai agent di folder proyek
nxc run "…"Jalankan prompt sekali lalu keluar
nxc webServer + antarmuka web lokal
nxc serveJalankan server headless
nxc providers loginTambah kredensial provider
nxc modelsDaftar model yang tersedia
nxc agentKelola agent kustom
nxc mcpKelola MCP server
nxc sessionKelola percakapan tersimpan
nxc export / importPindahkan sesi antar mesin
nxc upgradePerbarui ke versi terbaru
nxc --helpLihat semua perintah
